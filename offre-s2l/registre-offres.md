# Registre des offres J-Square

Toutes les offres faites ou envoyées, pour rester cohérent d'un client à l'autre. **On complète ce tableau à chaque nouvelle offre.**

Règles pour remplir le registre :
- Les prix sont hors taxe.
- Jay est en micro-entreprise : il ne facture pas de TVA tant qu'il reste sous le seuil de franchise.
- Le budget pub est toujours payé par le client directement à Meta ou Google. Il n'apparaît pas dans le prix J-Square.
- Ne jamais noter ici de téléphone ni d'e-mail : ils sont dans le CRM.
